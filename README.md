# AI Placement Coach Agent

An AI-powered placement preparation platform.

## Features
- Resume and job description analysis
- Personalized study plans
- Adaptive technical mock interviews
- AI answer evaluation
- Interview performance reports

## Technology
Python, Streamlit, Groq API, PyMuPDF, Plotly.

## Installation
pip install -r requirements.txt

## Run application
streamlit run app.py

## API configuration
Set GROQ_API_KEY as an environment variable.
Never upload your API key to GitHub.
